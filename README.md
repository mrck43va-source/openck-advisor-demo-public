# OpenCK Portfolio

Public interactive portfolio experience for OpenCK.

## Scope

Public portfolio only. No customer systems, production credentials, billing, private infrastructure, trading operations, or proprietary strategies are included.

The portfolio is supported by private internal automation and operating infrastructure.

## Features

- Responsive navigation for Home, Businesses, Products, How it works, Roadmap, For advisors, and Contact
- Interactive portfolio map and guided product journey
- Distinct product previews for CKTRADES, AI Content Studio, and Lead Response Automation
- Evidence-based release statuses
- Keyboard focus states and reduced-motion support
- Existing PWA, QR assets, install flow, icons, and scoped offline worker preserved
- No backend or runtime dependency

## Verification

Serve over HTTPS or a local static server and verify navigation, keyboard menu operation, touch layout, preview tabs, guided journey controls, manifest loading, service-worker fallback, and reduced-motion behavior.

No native iOS App Store availability is claimed. Synthetic demonstrations are not customer traction.
